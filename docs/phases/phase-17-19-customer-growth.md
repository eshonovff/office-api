# Фазаҳои 17–19 — Функсияҳои нав барои мизоҷон: Контактҳо, Рассылкаҳо, Аналитика

> Ҳолат: **нақша** (2026-09-25). Кор баъд аз тасдиқи корбар оғоз мешавад.
> Ҳама бе ИП бо аккаунтҳои тестер кор мекунад; баъди ИП ва App Review — барои ҳама.

## Мақсад

Бахшҳое, ки дар менюи мизоҷ ҳоло хира ҳастанд («Контактҳо», «Рассылкаҳо», «Аналитика»),
кушода шаванд — бо ҳамон қоидаҳои амният ва тарифе, ки дар фазаҳои 13–16 гузошта шуданд.

## Чӣ аллакай ҳаст (асос)

Маълумот барои ҳар се бахш аллакай ҷамъ мешавад — танҳо нишон дода намешавад:

| Маълумот | Ҷой | Кӣ ҷамъ мекунад |
|---|---|---|
| Контакт (ном, @username, расм, тирезаи 24-соата) | `conversations` (як сатр = як нафар дар як канал) | webhook-и паём/шарҳ, flow |
| Тегҳо | `contact_tags` (≤ 100 аломат) | амали flow «Илова кардани тег» |
| Тағйирёбандаҳо (ном, телефон, …) | `contact_variables` (калид ≤ 100, қимат ≤ 2000) | амали flow «Ҷамъоварии ҷавоб» |
| Сессияҳои автоматизатсия | `flow_sessions`, `flow_session_steps` | FlowEngine |
| Автоҷавоби шарҳ + натиҷаи санҷиши обуна | `automation_runs` | CommentAutomationJob |
| Шарҳҳо | `instagram_comments` | webhook, sync |
| Паёмҳо | `messages` | webhook, чатҳо |

Ҳамаи ин ҷадвалҳо аллакай филтри tenant доранд (ниг. `AppDbContext.ApplyTenantFilters`).
Frontend: `recharts` аллакай ҳаст (диаграммаҳо — бе package-и нав), TanStack Table ҳаст.

Тарифҳо (қарори 2026-09-24, `phase-13-subscriptions.md`): **контакт, чат ва рассылкаи
Instagram/Facebook — дар ҳама тарифҳо беҳад**; рассылкаи WhatsApp — танҳо Premium; ИИ-менеҷер
ва Virale — хизматҳои иловагӣ (add-on), на қисми тариф.

## ChatPlace чӣ дорад (аз ёрии расмии онҳо)

- **Контактҳо:** корти мизоҷ — ном, тамос, таърихи сӯҳбат, тегҳо ва маълумоти аз воронка
  ҷамъшуда; филтр барои рассылкаи сегментӣ; интеграция бо Google Sheets ва CRM.
- **Рассылкаҳо:** ном → аккаунт → паём бо ҳамон конструктори сценарий (матн, тугма, медиа ё
  оғози автоматизатсия); ба ҳама ё танҳо ба касоне, ки тег доранд; фаврӣ ё дар вақти муайян;
  баъди «Отправляется» бекор намешавад. Instagram: **танҳо ба касоне, ки дар 24 соати охир
  фаъолият кардаанд** (паём, ҷавоб ба сторис, пахши тугма, mention).
- **Аналитика:** барои ҳар автоматизатсия — «контактҳо» (оғозҳои беназир дар давра),
  «конверсия» (касоне, ки ба амали «Записать конверсию» расиданд), фоизи конверсия; давра
  (рӯз/моҳ/сол/дилхоҳ) бо муқоиса ба давраи пештара; диаграмма.
- **ИИ-агент** (LLM бо базаи дониш дар DM) ва **Virale** (ИИ барои ғояҳо ва сценарийи контент).

## Маҳдудиятҳои Meta

1. **Тирезаи 24-соата (Instagram):** ба корбар танҳо дар 24 соат баъди амали охирини ӯ паём
   фиристодан мумкин. Берун аз он роҳи қонунӣ барои рассылка нест (тег HUMAN_AGENT танҳо барои
   ҷавоби дастии корманд аст, на рассылка). Пас рассылка = танҳо ба «тирезаашон кушода».
2. **Ҳолати тестерӣ:** то App Review паём танҳо ба аккаунтҳои тестер меравад — барои санҷиш кофӣ.
3. **WhatsApp барои мизоҷ:** Embedded Signup → Tech Provider ва тасдиқи бизнес → баъди ИП.

## Фазаи 17 — Контактҳо (муфассал)

### Мақсад

Мизоҷ ҳамаи одамонеро, ки бо аккаунташ тамос гирифтаанд, дар як ҷо мебинад: кӣ ҳаст, чӣ
навишт, кадом тег ва маълумот (телефон, ном) дорад, аз кадом автоматизатсия гузашт, обуна ҳаст
ё не — ва метавонад тег гузорад, маълумотро ислоҳ кунад, ба Excel бардорад ва нест кунад.

### Backend

- [ ] 17.1 `GET /api/public/contacts` — `channelId`, `search` (ном/@username; `%`/`_` escape),
  `tag`, `page`, `pageSize ≤ 100`, `sort` (охирин фаъолият / аввалин тамос). Ҳар сатр: ном,
  @username, расм, тегҳо, 3 тағйирёбандаи аввал, аввалин тамос, охирин фаъолият, тиреза (то кай).
- [ ] 17.2 `GET /api/public/contacts/{id}` — корт: ҳама тегҳо ва тағйирёбандаҳо; таърихи
  автоматизатсия (номи flow, ҳолат, кай); автоҷавоби шарҳ (чанд бор, натиҷаи охирини санҷиши
  обуна); шумораи шарҳ ва паём; тиреза.
- [ ] 17.3 `GET /api/public/contacts/tags?channelId` — тегҳои мавҷуда бо шумора (барои филтр ва
  рассылка).
- [ ] 17.4 Тегҳо: `POST /{id}/tags {tag}`, `DELETE /{id}/tags/{tag}` — ≤ 100 аломат, ≤ 50 тег.
- [ ] 17.5 Тағйирёбандаҳо: `PUT /{id}/variables/{key} {value}`, `DELETE /{id}/variables/{key}` —
  калид `^[a-zA-Z0-9_]{1,100}$`, қимат ≤ 2000.
- [ ] 17.6 `GET /api/public/contacts/export?channelId&tag` — CSV (UTF-8 бо BOM барои Excel):
  ном, @username, пайванди профил, тегҳо, аввалин/охирин тамос, ҳар калиди тағйирёбанда —
  сутуни алоҳида. **Ҳимояи CSV-injection:** ячейкае, ки бо `= + - @ Tab CR` сар мешавад,
  бо `'` пешоянд мегирад. Rate limit (5/дақ). Дар log танҳо id ва шумора.
- [ ] 17.7 `DELETE /api/public/contacts/{id}` — нест кардани пурра: сӯҳбат, паёмҳо (бо
  файлҳои media дар диск), тегҳо, тағйирёбандаҳо, сессияҳо, шарҳҳои ӯ дар ин канал,
  `automation_runs`-и ӯ. `ContactDataEraser` — дар паҳлӯи `ChannelDataEraser`.
- [ ] 17.8 Тестҳо: validator-ҳо, CSV-injection, eraser, «актёри нодуруст» ба ҳар endpoint.

### Frontend

- [ ] 17.9 Менюи «Контактҳо» фаъол → `/account/contacts`.
- [ ] 17.10 Ҷадвал (компютер) / рӯйхат (телефон): ҷустуҷӯ, филтри тег, интихоби канал,

## Фазаи 18 — Рассылкаҳо (Instagram) — контур

- `broadcasts`: канал, ном, мундариҷа (паём: матн + расм + тугмаҳои пайванд — **ё** оғози
  автоматизатсия), аудитория (ҳама / тегҳо; истиснои тег), вақт (ҳозир ё дар вақти Душанбе),
  ҳолат (Draft → Scheduled → Sending → Done / Cancelled), шуморагарҳо.
- `broadcast_recipients` (ягона: рассылка + контакт) — ҳар нафар як бор; такрори job дубора
  намефиристад.
- Пеш аз фиристодан: «N нафар ҳоло дастрас (тирезаашон кушода) аз M».
- Job-и Hangfire: суръати маҳдуд (бар зидди спам); тиреза барои ҳар нафар дар лаҳзаи фиристодан
  аз нав санҷида мешавад → «гузаронда шуд: тиреза баста».
- Бекор кардан: пеш аз оғоз; ҳангоми фиристодан — боқимондаҳо қатъ мешаванд (беҳтар аз
  ChatPlace).
- Амният: tenant, тариф, rate limit, ҳадди мундариҷа, ҳеҷ паём берун аз тиреза.

## Фазаи 19 — Аналитика — контур

- Давра: 7 / 30 / 90 рӯз ё дилхоҳ (вақти Душанбе); муқоиса бо давраи пештара.
- Умумӣ: контактҳои нав, паём (воридотӣ/содиротӣ), шарҳҳо, ҷавобҳои худкор ва дастӣ,
  рассылкаҳо.
- Барои ҳар автоматизатсия: контактҳо (беназир), конверсия, фоиз. **Конверсия** — амали нави
  flow «Конверсия» (мисли ChatPlace); агар набошад — сессияҳои тамомшуда.
- Автоҷавоби шарҳ: иҷроҳо, ҷавобҳо, DM, хатоҳо; санҷиши обуна: «хоҳиши обуна → баъд обуна
  шуд» (конверсияи follow-gate).
- Постҳо: беҳтарин аз рӯи шарҳ. Диаграммаҳо бо `recharts`. Ҳисоб дар ҳамон лаҳза (бо индекс),
  кэши 5 дақ.
