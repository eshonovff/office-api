# Фазаи 15 — Чатҳои мизоҷ (Instagram DM)

> Ветка: `feat/phase-15-customer-chats` (office-web: `feat/fe-phase-15-customer-chats`)
> Вобаста: фазаи 14 (каналҳои мизоҷ, филтри tenant). Бахши "Чатҳо" дар менюи мизоҷ ҳоло хомӯш аст.

## Мақсад

Мизоҷ паёмҳои Instagram-и пайвастшудаи худро дар `/account/chats` мебинад ва ҷавоб медиҳад —
фавран (realtime), бе он ки ба Instagram гузарад. Ҳеҷ гоҳ чати мизоҷи дигар ё ширкатро намебинад.

## Доира (v1)

- Рӯйхати чатҳо аз ҳамаи каналҳои худ, аз нав ба кӯҳна; ҷустуҷӯ (ном / @username); "хонданашуда".
- Чат: таърихи паёмҳо (матн, расм, видео, овоз, ҷавоб ба story — ҳамон тавре ки кормандон мебинанд),
  вақти боқимондаи тирезаи 24-соатаи Meta.
- Ҷавоби **матнӣ** бо 45 сонияи бекоркунӣ (мисли кормандон) ва тугмаи "бекор".
- "Хонда шуд" ва нишонаи хонданашуда дар меню.
- Realtime: паёми нав ва ҳолати фиристодан фавран.

**Дар v1 нест** (баъдтар): фиристодани расм/овоз, қайдҳои дохилӣ, таъин ба аъзои даста, шаблонҳо,
рассылка, "ботро дар ин чат қатъ кун".

## Қарорҳо

| Савол | Қарор |
|---|---|
| Тариф гузашт | Хондани таърих — мумкин (маълумоти худаш); **фиристодан — не** (403 "тариф харед") |
| Мизоҷ ҷавоб медиҳад, вале автоматизатсия фаъол аст | Бот кор мекунад (мисли имрӯз барои кормандон). "Қатъ кардани бот дар чат" — баъдтар |
| Кӣ фиристод | `SentByUserId = null` (он ба кормандон ишора мекунад), `SentByUserName` = номи мизоҷ |
| Realtime | Hub-и алоҳида `/hubs/customer` (схемаи Customer). Гурӯҳ = `customer:{id}` аз **токен**, на аз клиент — методи "join" нест |

## Кор

- **Backend**
  - `/api/public/conversations`: `GET /`, `GET /{id}`, `GET /{id}/messages`, `POST /{id}/messages`,
    `POST /{id}/messages/{messageId}/cancel`, `POST /{id}/read`, `GET /unread-count`.
  - `/api/public/messages/{id}/media`, `/thumbnail`.
  - `CustomerHub` + `InboxEventPublisher` рӯйдодҳои каналҳои мизоҷро ба гурӯҳи соҳиб мефиристад.
  - Истифодаи такрорӣ: DTO-ҳои паём, `WhatsAppSendJob` (Instagram/Facebook-ро ҳам мефиристад), медиа.
- **Frontend:** `/account/chats` (ду панел дар desktop, як панел дар телефон), `MessageBubble`-и мавҷуда
  бо context-и API (медиа бо токени мизоҷ), меню бо шумораи хонданашуда.

## Definition of Done

3. Chrome: рӯйхат, чат, ҷавоб + бекор, паёми нав realtime, хонданашуда, телефон.
