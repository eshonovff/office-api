## Definition of Done
- Аз телефони шахсӣ ба рақами тестӣ паём → дар база пайдо мешавад
- Ҷавоб аз API → ба телефон мерасад
- Статуси `delivered`/`read` нав мешавад
- Расми фиристодашуда ба сервер нусхабардорӣ мешавад ва баъди мӯҳлати Meta ҳам кушода мешавад
