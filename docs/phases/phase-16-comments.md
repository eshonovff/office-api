# Фазаи 16 — Шарҳҳои Instagram: ҷавоби оммавӣ ва модератсия

> Ветка: `feat/phase-16-comments` (office-web: `feat/fe-phase-16-comments`), аз фазаи 15.
> Иҷозати Meta: `instagram_business_manage_comments` (аллакай дар пайваст дархост мешавад).

## Мақсад

1. **Автоматӣ:** шарҳ → ҷавоби кӯтоҳ **зери пост** ("Ба Direct навиштем 📩") + паём дар Direct.
2. **Дастӣ:** саҳифаи "Шарҳҳо" — мизоҷ шарҳҳои постҳои худро мебинад ва ҷавоб медиҳад, ба Direct
   менависад, пинҳон ё нест мекунад.

## Ҳолати имрӯза (таҳлил)

| | Мизоҷ (Flow Builder) | Кормандон (қоидаи оддӣ) |
|---|---|---|
| Шарҳ → Direct | ✅ | ✅ |
| Ҷавоби оммавӣ зери пост | ❌ | ✅ (вариантҳо бо навбат) |
| Дидан / ҷавоби дастӣ / пинҳон / нест | ❌ | ❌ |
| Шарҳҳо дар база | ❌ — танҳо автоматизатсияро сар мекунанд | ❌ |

Хатои мавҷуда: `InstagramPayloadParser.TryParseCommentEvent` танҳо **аввалин** шарҳи webhook-ро
мехонад — вақте Meta якчанд шарҳро якҷоя мефиристад, боқимонда гум мешаванд. `parent_id` (ҷавоб ба
шарҳ) низ хонда намешавад.

## Қоидаҳои Meta

| Амал | Graph API | Маҳдудият |
|---|---|---|
| Ҷавоби оммавӣ | `POST /{comment-id}/replies` | шумора нест; матни якхела пай дар пай = шубҳаи спам → вариантҳо + таъхир |
| Direct аз шарҳ (private reply) | `POST /me/messages` `recipient.comment_id` | **як бор** барои шарҳ, танҳо **7 рӯз** |
| Пинҳон / намоён | `POST /{comment-id}?hide=true/false` | — |
| Нест кардан | `DELETE /{comment-id}` | барнагарданда |
| Шарҳҳои пост | `GET /{media-id}/comments` | лимити умумии Graph → синхрон на зудтар аз 1 бор дар 5 дақ барои пост |

То App Review — танҳо барои аккаунтҳои тестер.

## Қарорҳо (метавонед иваз кунед)

- Саҳифа **танҳо барои мизоҷ**; кормандон қоидаҳои худро нигоҳ медоранд (саҳифаи онҳо — баъдтар,
  backend ҳамон мешавад).
- Шарҳҳо дар база то вақте ки канал ё ҳисоб нест карда нашавад нигоҳ дошта мешаванд (мисли чатҳо).
- Дидан — бе тариф; ҳар амал (ҷавоб, Direct, пинҳон, нест, синхрон) — бо тариф.
- Ҷавоби дастӣ ва автоматӣ ҳарду зери шарҳ ҳамчун "ҷавоби шумо" нишон дода мешаванд (автоматӣ бо 🤖).

## Кор

### Backend
- **16.1** Parser: ҳамаи `entry[]` ва `changes[]`, `parent_id`, навъи пост; тестҳо.
- **16.2** `InstagramComment` (канал, id-и Meta — ягона дар канал, пост, `parent`, муаллиф, матн, вақт,
  "аз худи аккаунт", пинҳон, Direct фиристода шуд, хонда шуд, 🤖) + migration + **филтри tenant**
  (15-ум) + `ChannelDataEraser`.
- **16.3** Webhook: шарҳ аввал сабт мешавад (идемпотентӣ), баъд автоматизатсия; рӯйдоди realtime ба соҳиб.
- **16.4** Қадами 1: `publicReplies` (0–5 вариант) дар триггери "Шарҳ"-и flow → `CommentPublicReplyJob`
  (бо навбат, таъхири 5–20 с), ҷавоб сабт мешавад, хато нишон дода мешавад; шаблони "Ҷавоб ба
  комментарий + DM" нав мешавад.
- **16.5** Direct-и автоматизатсия (flow ва қоидаи кормандон) дар шарҳ қайд мешавад — то дастӣ дубора
  фиристода нашавад.
- **16.6** Provider: `ListCommentsAsync`, `HideCommentAsync`, `DeleteCommentAsync`.
- **16.7** `/api/public/comments`: постҳо (аз Graph + шумораҳо аз база), шарҳҳои пост (дарахт, филтрҳо:
  нав / бе ҷавоб / пинҳон), ҷавоб, Direct, пинҳон/намоён, нест, синхрон, "хонда шуд", шумораи нав.

### Frontend
- **16.8** Flow Builder: танзимоти триггери "Шарҳ" — "Зери пост ҳам ҷавоб нависед" + вариантҳо.
- **16.9** `/account/comments`: постҳо (чап) ва шарҳҳо бо ҷавобҳо (рост), амалҳо дар ҳар шарҳ,
  тасдиқ пеш аз нест кардан, филтрҳо, телефон; менюи "Шарҳҳо" бо шумораи нав; realtime.
