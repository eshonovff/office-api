# Фазаи 16 — Шарҳҳои Instagram: ҷавоби оммавӣ ва модератсия

> Ветка: `feat/phase-16-comments` (office-web: `feat/fe-phase-16-comments`), аз фазаи 15.
> Иҷозати Meta: `instagram_business_manage_comments` (аллакай дар пайваст дархост мешавад).

## Мақсад

1. **Автоматӣ:** шарҳ → ҷавоби кӯтоҳ **зери пост** ("Ба Direct навиштем 📩") + паём дар Direct.
2. **Дастӣ:** саҳифаи "Шарҳҳо" — мизоҷ шарҳҳои постҳои худро мебинад ва ҷавоб медиҳад, ба Direct
   менависад, пинҳон ё нест мекунад.

## Ҳолати имрӯза (таҳлил)

| | Мизоҷ (Flow Builder) | Кормандон (қоидаи оддӣ) |
|---|---|---|
| Шарҳ → Direct | ✅ | ✅ |
| Ҷавоби оммавӣ зери пост | ❌ | ✅ (вариантҳо бо навбат) |
| Дидан / ҷавоби дастӣ / пинҳон / нест | ❌ | ❌ |
| Шарҳҳо дар база | ❌ — танҳо автоматизатсияро сар мекунанд | ❌ |

Хатои мавҷуда: `InstagramPayloadParser.TryParseCommentEvent` танҳо **аввалин** шарҳи webhook-ро
мехонад — вақте Meta якчанд шарҳро якҷоя мефиристад, боқимонда гум мешаванд. `parent_id` (ҷавоб ба
шарҳ) низ хонда намешавад.

## Қоидаҳои Meta

| Амал | Graph API | Маҳдудият |
|---|---|---|
| Ҷавоби оммавӣ | `POST /{comment-id}/replies` | шумора нест; матни якхела пай дар пай = шубҳаи спам → вариантҳо + таъхир |
| Direct аз шарҳ (private reply) | `POST /me/messages` `recipient.comment_id` | **як бор** барои шарҳ, танҳо **7 рӯз** |
| Пинҳон / намоён | `POST /{comment-id}?hide=true/false` | — |
| Нест кардан | `DELETE /{comment-id}` | барнагарданда |
| Шарҳҳои пост | `GET /{media-id}/comments` | лимити умумии Graph → синхрон на зудтар аз 1 бор дар 5 дақ барои пост |

То App Review — танҳо барои аккаунтҳои тестер.

## Қарорҳо (метавонед иваз кунед)

- Саҳифа **танҳо барои мизоҷ**; кормандон қоидаҳои худро нигоҳ медоранд (саҳифаи онҳо — баъдтар,
  backend ҳамон мешавад).
- Шарҳҳо дар база то вақте ки канал ё ҳисоб нест карда нашавад нигоҳ дошта мешаванд (мисли чатҳо).
- Дидан — бе тариф; ҳар амал (ҷавоб, Direct, пинҳон, нест, синхрон) — бо тариф.
- Ҷавоби дастӣ ва автоматӣ ҳарду зери шарҳ ҳамчун "ҷавоби шумо" нишон дода мешаванд (автоматӣ бо 🤖).

## Кор

  (15-ум) + `ChannelDataEraser`.
- **16.3** Webhook: шарҳ аввал сабт мешавад (идемпотентӣ), баъд автоматизатсия; рӯйдоди realtime ба соҳиб.
- **16.4** Қадами 1: `publicReplies` (0–5 вариант) дар триггери "Шарҳ"-и flow → `CommentPublicReplyJob`
  (бо навбат, таъхири 5–20 с), ҷавоб сабт мешавад, хато нишон дода мешавад; шаблони "Ҷавоб ба
  комментарий + DM" нав мешавад.
- **16.5** Direct-и автоматизатсия (flow ва қоидаи кормандон) дар шарҳ қайд мешавад — то дастӣ дубора
  фиристода нашавад.
- **16.6** Provider: `ListCommentsAsync`, `HideCommentAsync`, `DeleteCommentAsync`.
- **16.7** `/api/public/comments`: постҳо (аз Graph + шумораҳо аз база), шарҳҳои пост (дарахт, филтрҳо:
  нав / бе ҷавоб / пинҳон), ҷавоб, Direct, пинҳон/намоён, нест, синхрон, "хонда шуд", шумораи нав.

### Frontend
- **16.8** Flow Builder: танзимоти триггери "Шарҳ" — "Зери пост ҳам ҷавоб нависед" + вариантҳо.
- **16.9** `/account/comments`: постҳо (чап) ва шарҳҳо бо ҷавобҳо (рост), амалҳо дар ҳар шарҳ,
  тасдиқ пеш аз нест кардан, филтрҳо, телефон; менюи "Шарҳҳо" бо шумораи нав; realtime.

- **Амният (пеш аз ин фаза ҳам буд):** Meta метавонад дар як webhook `entry[]`-и чанд аккаунтро

## Навсозӣ (2026-09-25): ҷавоб бо санҷиши обуна

Дархости корбар: мисли автоматизатсияи кӯҳна (фазаи 11) — обуначӣ як паём мегирад, касе ки
обуна нест паёми дигар. Шаблони нав **«Ҷавоб ба шарҳ бо санҷиши обуна»**:

- `check` (шарт: обуна) → ҳа: паём барои обуначиён; не: «аввал обуна шавед» бо тугмаи
  «Обуна шудам ✅».
- Тугма ба `recheck` (санҷиши дуюм) меравад, на ба `check`: FlowEngine аз гиреҳе оғоз мекунад,
  ки ба он ҳеҷ пайванд намеояд. Ҳар давр интизори пахши тугма аст — худ ба худ давр намезанад.
- Паёми аввал (кадоме бошад) — private reply-и ягонаи шарҳ; пас аз пахши тугма тиреза кушода
  аст ва паёмҳо оддӣ мераванд. «Обуна нест» кэш намешавад, пас санҷиши дуюм тоза аст.
- Тестҳо (бо HTTP-и сохта): обуначӣ → private reply; обуна нест → хоҳиш → пахш бе обуна → боз
  хоҳиш → обуна + пахш → паём барои обуначиён; ва сохтор (ягона оғоз — `check`). Мутатсия
  (тугма → `check`) тести сохторро ноком мекунад.
- Дар canvas-и мизоҷ ҳам гиреҳи «Шарт» бо майдони «Обуна» ҳаст — flow-ҳои мавҷударо дастӣ ҳам
  ҳамин тавр сохтан мумкин.

## Навсозӣ (2026-09-25): автоҷавоби шарҳ дар саҳифаи «Шарҳҳо»

Дархости корбар: автоҷавоби шарҳ барои мизоҷ **айнан** мисли автоматизатсияи кормандон бошад ва
дар саҳифаи «Шарҳҳо» ҷой гирад, на дар «Автоматизатсияҳо». Чизи зиёдатӣ сохта нашавад.

Сохта шуд:
- Таби «Автоҷавоб» дар `/account/comments`: қоидаҳои кормандон (`automation_rules`) бо ҳамон
  форма (`RuleFormModal`): калимаҳо ва постҳо, якчанд ҷавоб зери шарҳ бо навбат, DM ва тугма,
  санҷиши обуна бо шохаи «обуна шавед ва аз нав нависед», cooldown ва санҷиши пешакӣ.
- `/api/public/channels/{id}/automation-rules` (`CustomerCommentRulesEndpoints`): handler-ҳои
  кормандон; филтри tenant → бегона 404; `CustomerOnly`. Офаридан ва фаъол кардан бо тариф ва дар
  ҳадди `ActiveAutomations`. Ин ҳад акнун flow-ҳо ва қоидаҳоро **якҷоя** ҳисоб мекунад, вагарна
  қоидаҳо роҳи гузаштан аз тариф мешуданд. Таҳрир, хомӯш ва нест бе тариф ҳам мумкин.
- `CommentAutomationProcessor` ва `CommentAutomationJob` барои канали мизоҷ тарифро месанҷанд
  (`AutomationRunGate`). Каналҳои кормандон мисли пештара кор мекунанд.
- Job ҷавоби фиристодаро дар саҳифаи «Шарҳҳо» бо 🤖 сабт мекунад, сабаби рад шуданро дар худи шарҳ
  нигоҳ медорад ва `CommentsUpdated` мефиристад.

Хатоҳое, ки ислоҳ шуданд (ба кормандон ҳам дахл доранд):
- **Баъд аз «обуна шавед ва аз нав нависед»:** шарҳи нав дар давоми cooldown (пешфарз 60 дақ)
  рад мешуд ва ҳеҷ ҷавоб намерафт. Эҳтимол ҳамин баги корбар буд («камент кардам, ҷавоб наомад»).
  Акнун чунин шарҳ ба job мегузарад ва обуна аз нав санҷида мешавад: агар обуна шуда бошад, ҷавоби
  обуначӣ меравад; агар ҳанӯз обуна набошад, хоҳиши дубора намеравад, то спам нашавад.
- **Cooldown аз шарҳҳои радшуда дароз мешуд:** касе, ки ҳар 30 дақ шарҳ менавишт, дигар ҳеҷ гоҳ
  ҷавоб намегирифт. Акнун cooldown аз ҷавоби охирини воқеан фиристодашуда ҳисоб мешавад.
- Ҷавоб ба шарҳе, ки худаш ҷавоб аст, зери шарҳи асосӣ меравад (Instagram як сатҳ дорад).
- Dry-run: ID-и корбар бевосита ба суроғаи Graph API мегузашт. Акнун танҳо рақам қабул мешавад
  ва ҳангоми сохтани суроға escape мешавад.
- Ҳадҳо барои ҳамаи майдонҳои қоида: калимаҳо 50×100, постҳо 100 (танҳо рақам ва `_`), ҷавобҳо
  10×1000, DM 1000, пайвандҳо танҳо http(s), cooldown то 30 рӯз.

Нест карда шуд (такрори ҳамон кор дар ду ҷой):
- Ҷавоб зери шарҳ дар танзимоти flow (`publicReplies`, `CommentPublicReplyJob`).
- Шаблони «Ҷавоб ба шарҳ бо санҷиши обуна». Seed сатри онро аз база тоза мекунад; flow-ҳое, ки аз
  он сохта шудаанд, мемонанд.
- Вариантҳои матни DM дар flow-ҳо мемонанд: онҳо ба чат дахл доранд ва чизеро такрор намекунанд.

Санҷишҳо:
- Backend: 864 тест. Нав: cooldown (ҳарду хато), санҷиши тариф дар processor ва job, 🤖 ва сабаби
