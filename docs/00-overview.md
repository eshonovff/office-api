# 00 — Тасвири умумӣ

## Масъала

Ҳозир таскҳо дар Telegram ва даҳон навишта мешаванд, паёмҳои мижозон дар се барнома пароканда (Instagram, Facebook, WhatsApp) ва як шахс ба ҳама ҷавоб медиҳад. Кӣ чиро кард маълум нест.

## Ҳал

Як платформаи дохилӣ ки:
- Таскро ба корманд медиҳад ва ҳолаташро нишон медиҳад
- Ҳамаи паёмҳоро дар як инбокс ҷамъ мекунад
- Ҳар чатро ба як корманд таъин мекунад ва ҳолаташро пайгирӣ мекунад
- Ба ҳар корманд танҳо ҳамон қисмро мекушояд ки лозим аст

## Корбарон

| Роль | Чӣ мекунад |
|---|---|
| Owner | Ҳама чиз. Корманд месозад, доступ медиҳад |
| Admin | Ҳама чиз ғайр аз идораи кормандон |
| Developer | Таск мебинад, месозад, мекӯчонад |
| Operator | Танҳо ба чатҳо ҷавоб медиҳад |
| Manager | Чатҳоро тақсим мекунад, таск месозад |

**Муҳим:** як нафар якчанд роль дошта метавонад (Developer + Operator).
