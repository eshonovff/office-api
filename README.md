# office-api

Backend-и платформаи дохилии SMARTWEB TJ — `office.nizom.tj`.

Кормандон ва доступи дақиқ, проект/таск бо drag & drop, пайвасти Instagram/Facebook/WhatsApp, инбокси умумӣ. Барои худамон, на барои мижозон.

## Оғози кор

```
./dev.sh
```

Усули стандартии оғоз ҳамин аст, на `dotnet run`-и мустақим — скрипт Docker-ро месанҷад, PostgreSQL-ро боло мекунад, интизори омода шуданашро мешавад ва баъд API-ро сар медиҳад.
